# 핀볼 게임 (Pinball Rush) 작업 내역 및 명세서

- 프로젝트명: Pinball Rush (핀볼 러시)
- 배포 실서버 URL: https://wisekks-arch.github.io/gostop/pinball/index.html

## 3대 명작 핀볼 머신 선택 시스템 구축 (최신 반영)
사용자가 직접 실사 사진으로 업로드한 전설적인 3대 명작 핀볼 머신을 선택하여 플레이할 수 있는 멀티 머신 선택 시스템 완성:

1. **머신 1: 🦸‍♂️ 어벤져스 : 인피니티 퀘스트 (Avengers Infinity Quest)**
   - 배경 텍스처: `assets/table_avengers.jpg`
   - 상단 전광판: `🦸‍♂️ AVENGERS` / `INFINITY QUEST` / `💎 6 STONES`
   - 주요 기믹: 상단 타노스 인피니티 건틀릿 팝범퍼, 헐크/아이언맨/캡틴 범퍼, 인피니티 스톤 조명
   - BGM: 영웅적인 어벤져스 브라스 팡파레 & 펀치 베이스 신스

2. **머신 2: 🏴‍☠️ 블랙 로즈 : 싱크 쉽 (Black Rose : Sink Ship)**
   - 배경 텍스처: `assets/table_pirate.jpg`
   - 상단 전광판: `🏴‍☠️ BLACK ROSE` / `SINK SHIP!` / `⚓ JACKPOT`
   - 주요 기믹: 중앙 회전 대포(Cannon 발사 핫스팟), SINK SHIP 군함 침몰 잭팟, 해적 돛대 범퍼
   - BGM: 박진감 넘치는 해적선 대포 아케이드 칩튠 비트

3. **머신 3: 🚀 가디언즈 오브 갤럭시 (Guardians of the Galaxy)**
   - 배경 텍스처: `assets/table_guardians.jpg`
   - 상단 전광판: `🚀 GROOT` / `GUARDIANS` / `🎧 STAR-LORD`
   - 주요 기믹: 상단 거대 그루트(Groot) 인터랙티브 범퍼, 스타로드 믹스테이프 Vol.2, 코스믹 워프게이트
   - BGM: 7080 레트로 디스코 펑키 팝 신스 아르페지오

## 주요 UI/UX 개선사항
- **명언 배너 카드 탑재**: "단순한데 왜 이렇게 재밌을까? 핀볼게임의 숨은 매력" 네온 펄스 배너
- **로비 3대 머신 선택 카드**: 원클릭으로 어벤져스/블랙로즈/가디언즈 즉시 선택 및 네온 하이라이트
- **인게임 상단 HUD 퀵 머신 전환**: 게임 중에도 상단 버튼(`[🦸‍♂️ 어벤져스 🔄]`)을 탭하여 실시간 머신 및 BGM 스위칭 지원
- **사운드 지연시간 0초**: Web Audio API 내장 신시사이저를 통해 별도 음원 파일 없이 즉각 반응
