# StockCraft (스톡크래프트) 프로젝트 요구사항 및 프롬프터 명세서

## 1. 프로젝트 개요
• 서비스명(가칭): StockCraft (스톡크래프트)
• 배포 URL: https://wisekks-arch.github.io/gostop/stock/index.html
• 목적: 실전 투자 전 리스크 없이 모의투자를 경험하고, 실제 주식 보유 현황을 엑셀로 업로드하여 포트폴리오 관리, 기술적 지표 조정, 그리고 리밸런싱 전략을 검증할 수 있는 주식 시뮬레이션 웹 플랫폼 구축
• 주요 타깃:
  - 주식 투자를 처음 시작하는 사회초년생 및 초보 투자자
  - 실제 주식 계좌를 보유하고 있으며 비중 조절 및 리밸런싱을 검증하려는 실전 투자자
  - 코스피, 코스닥, S&P 500, 나스닥 등 실시간 시장 지수 동향을 정확히 파악하며 매매하려는 투자자
  - RSI, 이동평균선 등 기술적 지표와 익절/손절/비중 규칙을 직접 조절해 검증하려는 퀀트/전략 투자자
  - 스마트폰(갤럭시 S26+ 등 모바일 환경) 및 PC 어디서나 원활하게 접속하여 실시간 차트와 리밸런싱을 관리하려는 모바일 투자자

## 2. 핵심 타깃 분석 및 핵심 가치 (Value Proposition)
1) 모바일 & 실전 투자자 (갤럭시 S26+ 및 스마트폰 사용자)
  - 페인 포인트: PC 중심의 복잡한 화면으로 인해 스마트폰 접속 시 요소 겹침, 테이블 잘림, 스크롤 낭비 발생
  - 플랫폼 제공 가치: 모바일 MTS(Mobile Trading System) 최적화 반응형 레이아웃, 헤더 2단 배치, 차트 터치 제스처, 데이터 테이블 가로 스와이프 지원
2) 실전 시세 파악 투자자
  - 페인 포인트: 허위 정적 지수 데이터로 인한 시장 추세 판단 혼선
  - 플랫폼 제공 가치: 🌐 코스피, 코스닥, S&P 500, 나스닥 4대 주요 지수 글로벌 공인 금융 API 실시간 연동 및 60초 자동 갱신
3) 투자 입문자
  - 페인 포인트: 원금 손실에 대한 두려움, 낯선 HTS/MTS UI
  - 플랫폼 제공 가치: 가상 자산 지원, 직관적인 UI/UX, 기본 금융 튜토리얼
4) 실전 투자자
  - 페인 포인트: 실제 보유 주식의 쏠림 위험 및 리밸런싱 시점 포착 어려움
  - 플랫폼 제공 가치: 엑셀 잔고 파일 업로드로 즉시 내 자산 단독 등록 & AI 리밸런싱 처방
5) 전략 검증자
  - 페인 포인트: 기술적 지표 및 매매 룰 변경에 따른 포트폴리오 영향 검증 한계
  - 플랫폼 제공 가치: ⚙️ 기술적 지표 & 전략 파라미터 커스텀 설정 대시보드 제공 (RSI, MA, 익절/손절선 실시간 반영)

## 3. 주요 기능 명세 (Feature Scope)
가. 🌐 시장 주요 4대 지수 실시간 공인 금융 API 연동 [신규 완비]
• 코스피 (KOSPI - ^KS11): 최신 정규장 실제 지수, 전일대비 변동치, 등락률(%) 실시간 수신 및 표시
• 코스닥 (KOSDAQ - ^KQ11): 최신 정규장 실제 지수, 전일대비 변동치, 등락률(%) 실시간 수신 및 표시
• S&P 500 (^GSPC): 미국 정규장 최신 마감 실제 지수, 변동폭, 등락률(%) 실시간 수신 및 표시
• 나스닥 종합 (NASDAQ - ^IXIC): 미국 정규장 최신 마감 실제 지수, 변동폭, 등락률(%) 실시간 수신 및 표시
• 비동기 연동 엔진:
  - 야후 파이낸스(Yahoo Finance) 및 한국거래소 공인 시세 API 기반 실시간 커넥터 (`fetchLiveMarketIndices`)
  - 브라우저 CORS 제한 극복을 위한 검증된 프록시 풀(`corsproxy.io`, `allorigins`, `codetabs`) 순차 폴백
  - 깜빡임 없는 사용자 경험을 위한 2026년 최신 실제 지수 기본 캐시 탑재
  - 60초 주기 자동 새로고침 및 상단 '🔄 실시간 시세 동기화' 버튼 연동

나. 모바일(갤럭시 S26+ 등) 전용 반응형 MTS UI/UX 최적화
• 📱 헤더 2단 컴팩트 레이아웃:
  - 1단: 좌측 [로고 + 배지] / 우측 [다크모드 + 새로고침 + 리셋 + 설정 버튼] 횡배치
  - 2단: [총평가자산 | 총손익/수익률 | 예수금] 3대 핵심 자산을 모바일 화면에 꼭 맞춘 그리드로 꽉 차게 정렬
• 👆 5대 메뉴 탭 바 터치 스와이프:
  - 모바일 터치 스와이프 친화적 가로 스크롤 (`-webkit-overflow-scrolling: touch; scrollbar-width: none;`)
  - 탭 버튼 터치 타깃 44px 이상 확보 및 폰트/패딩 최적화
• 📈 모바일 트레이딩룸 (MTS 스타일):
  - 종목 선택 영역 높이 제한(`max-height: 200px`)으로 불필요한 스크롤 낭비 방지
  - 캔들 차트 캔버스 높이 280~300px 최적화로 한 화면에서 차트와 호가창을 한눈에 조망
  - 캔버스 터치 제스처(`touchstart`, `touchmove`, `touchend`) 바인딩으로 손가락 터치 시 캔들 상세 시세 오버레이 표시
  - 차트 주기(1D/1W/60M) 및 작도 툴바 가로 터치 스크롤 지원
  - 호가창 및 매수/매도 주문 버튼 터치 크기 확대(시원하고 오타 없는 터치 지원)
• 📊 전 화면 데이터 테이블 모바일 가로 스와이프:
  - 홈 현황, 포트폴리오 잔고, 리밸런싱 실행 테이블, 엑셀 파싱 목록 등 모든 테이블 카드에 `overflow-x: auto` 적용하여 모바일 화면 깨짐 100% 방지
• ⚙️ 지표 & 전략 설정 대시보드 모바일 최적화:
  - 4대 설정 카드를 모바일 1열(100% 너비)로 시원하게 배치, 입력창 터치 패딩 최적화
  - 상단 바로가기/저장/복원 버튼 모바일 세로 풀-너비 터치 버튼으로 정렬

다. 가상 자산 및 계좌 시스템
• 가상 시드머니 모드: 가입/리셋 시 기본 1억 원(예수금 4,500만 원 + 기본 종목) 자동 지원
• 엑셀 실자산 단독 모드: 엑셀 업로드 시 기존 가상 예수금과 1억 기준선 100% 완전 삭제 리셋
  - 총평가자산: 내가 등록한 엑셀 주식들의 총 평가금액만 단독 표시
  - 예수금: 0원 (기존 가상 잔여 예수금 완전 배제)
  - 총손익 및 수익률: 내가 등록한 종목들의 매입원금 대비 순수 평가손익 및 수익률(%)만 단독 표시
• 수수료 및 세금 시뮬레이션: 위탁수수료(0.015%) 및 증권거래세(0.18%) 자동 차감 반영
• 계좌 초기화 기능: '🔄 계좌 리셋' 버튼 클릭 시 언제든 1억 원 및 기본 시장 종목 목록으로 복원 가능

라. 주문 및 체결 엔진
• 지원 시장: 국내 주식(KOSPI, KOSDAQ), 미국 주식(NYSE, NASDAQ)
• 호가 및 주문 유형: 시장가, 지정가, 스탑로스 주문
• 시세 데이터 연동:
  - ✏️ 실시간 현재가 직접 수정/동기화(updateStockPrice)
  - 🔄 원클릭 외부 실시간 시세 동기화 (네이버/야후/키움)

마. 📊 트레이딩룸 인터랙티브 차트 매니저 [실제 증시 API & 줌 엔진 완비]
• 🌐 실제 공인 금융 API (네이버 금융 fchart / 야후 파이낸스) 차트 데이터 100% 실시간 연동:
  - 허위 난수 차트를 배제하고 실제 거래소 과거 및 최신 시/고/저/종/거래량 캔들스틱 정밀 렌더링
  - 국내 종목: 네이버 금융 fchart 공식 API (일봉/주봉) 및 야후 파이낸스 실시간 시세 (60분봉) 연동
  - 해외 종목: 야후 파이낸스 실시간 차트 API (일봉/주봉/60분봉) 연동
  - 10대 대표 종목 실제 거래소 캔들 아카이브 탑재
• 🔍 차트 크게보기 (+) / 작게보기 (-) / 100% 줌 컨트롤 및 마우스 휠 줌(Wheel Zoom)
• ⏱️ 차트 주기(Timeframe) 원클릭 전환 (일봉 1D / 주봉 1W / 60분봉 60M)
• 🛠️ 차트 보조선 작도 툴킷: 수평 지지/저항선, 자유 추세선, 피보나치 되돌림선, 볼린저 밴드(20, 2), 내 평단가선, 작도 지우기
• 🌓 다크 모드 / 화이트 모드 2가지 테마 지원
• 📐 전체 화면 테이블 항목별 표준 정렬 체계 완비 (종목명 좌측, 수치 우측, 상태 중앙)

바. 📑 실제 주식 잔고 엑셀 업로드 [전 영역 완전 무결성 단독 동기화]
• 🔄 기존 주식 및 가상 예수금 100% 완전 삭제 후 엑셀 주식만 단독 교체 등록 (Replace All)
• 📊 5대 전 화면 실시간 일괄 동시 연동

사. ⚖️ 리밸런싱 전략 엔진 및 ⚙️ 기술적 지표 & 전략 파라미터 대시보드
1) [옵션 1] 개별 단일 종목 리밸런싱 전략 (Single-Stock Strategy)
2) [옵션 2] 전체 보유 종목 포트폴리오 리밸런싱 전략 (Whole-Portfolio Strategy, 선택 종목만 일괄 리밸런싱)
3) [옵션 3 & 전용 메인 탭] ⚙️ 기술적 지표 & 전략 파라미터 설정 대시보드 (tabPane-config)
  - RSI, 이동평균선, 익절/손절, 편중도/현금 버퍼 파라미터 실시간 저장 및 반영

## 4. 개편된 5대 정보 구조도 (IA: Information Architecture)
StockCraft (상단 5대 메인 네비게이션 체계 & 모바일 MTS 완비)
├── 1. 📊 종목 시세 & 매매 (tabPane-trading)
│   ├── 🌐 실시간 4대 지수 티커 배너 (코스피, 코스닥, S&P 500, 나스닥)
│   ├── 엑셀 등록 주식 단독 리스트 (모바일 컴팩트 스크롤)
│   ├── ⏱️ 시세 차트 주기 선택 (일봉 1D / 주봉 1W / 60분봉 60M)
│   ├── 🔍 차트 줌 컨트롤 & 모바일 터치 제스처 지원
│   ├── 🛠️ 차트 보조선 작도 툴킷
│   └── 10단계 호가창 및 모바일 친화 주문 패널
├── 2. 💼 보유 주식 포트폴리오 (tabPane-portfolio)
│   ├── 보유 잔고 테이블 (항목별 표준 정렬, 모바일 가로 스와이프)
│   ├── 자산 배분 비중 분석 (도넛 차트)
│   └── 상세 트레이딩 통계
├── 3. ⚖️ 리밸런싱 전략실 (tabPane-rebalance)
│   ├── [옵션 1] 개별 종목 전망 및 리밸런싱 진단
│   ├── [옵션 2] 전체 보유 종목 일괄 리밸런싱 시뮬레이터 (선택 종목만 일괄 체결)
│   └── [옵션 3 카드] 클릭 시 ⚙️ 지표 & 전략 설정 대시보드로 즉시 전환
├── 4. ⚙️ 지표 & 전략 설정 (tabPane-config)
│   ├── 4대 설정 카드 모바일 1열 시원한 카드 뷰 (RSI, MA, 익절/손절, 편중도)
│   └── 모바일 풀-너비 액션 버튼 (저장/복원/리밸런싱 바로가기)
└── 5. 📑 엑셀 업로드 시뮬 (tabPane-excel)
    ├── 모바일 터치 친화 업로드 존 & 샘플 다운로드
    └── 업로드 파싱 데이터 실시간 가로 스와이프 미리보기 및 일괄 적용
