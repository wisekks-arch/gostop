# StockCraft (스톡크래프트) 프로젝트 요구사항 및 프롬프터 명세서

## 1. 프로젝트 개요
• 서비스명(가칭): StockCraft (스톡크래프트)
• 배포 URL: https://wisekks-arch.github.io/gostop/stock/index.html
• 목적: 실전 투자 전 리스크 없이 모의투자를 경험하고, 실제 주식 보유 현황을 엑셀로 업로드하여 포트폴리오 관리, 기술적 지표 조정, 그리고 리밸런싱 전략을 검증할 수 있는 주식 시뮬레이션 웹 플랫폼 구축
• 주요 타깃:
  - 주식 투자를 처음 시작하는 사회초년생 및 초보 투자자
  - 실제 주식 계좌를 보유하고 있으며 비중 조절 및 리밸런싱을 검증하려는 실전 투자자
  - RSI, 이동평균선 등 기술적 지표와 익절/손절/비중 규칙을 직접 조절해 검증하려는 퀀트/전략 투자자
  - 경제 및 금융 교육 목적의 동아리, 학교, 스터디 그룹

## 2. 핵심 타깃 분석 및 핵심 가치 (Value Proposition)
1) 투자 입문자
  - 페인 포인트: 원금 손실에 대한 두려움, 낯선 HTS/MTS UI
  - 플랫폼 제공 가치: 가상 자산 지원, 직관적인 UI/UX, 기본 금융 튜토리얼
2) 실전 투자자
  - 페인 포인트: 실제 보유 주식의 쏠림 위험 및 리밸런싱 시점 포착 어려움
  - 플랫폼 제공 가치: 엑셀 잔고 파일 업로드로 즉시 내 자산 단독 등록 & AI 리밸런싱 처방
3) 전략 검증자
  - 페인 포인트: 기술적 지표 및 매매 룰 변경에 따른 포트폴리오 영향 검증 한계
  - 플랫폼 제공 가치: ⚙️ 기술적 지표 & 전략 파라미터 커스텀 설정 대시보드 제공 (RSI, MA, 익절/손절선 실시간 반영)

## 3. 주요 기능 명세 (Feature Scope)
가. 가상 자산 및 계좌 시스템
• 가상 시드머니 모드: 가입/리셋 시 기본 1억 원(예수금 4,500만 원 + 기본 종목) 자동 지원
• 엑셀 실자산 단독 모드: 엑셀 업로드 시 기존 가상 예수금과 1억 기준선 100% 완전 삭제 리셋
  - 총평가자산: 내가 등록한 엑셀 주식들의 총 평가금액만 단독 표시
  - 예수금: 0원 (기존 가상 잔여 예수금 완전 배제)
  - 총손익 및 수익률: 내가 등록한 종목들의 매입원금 대비 순수 평가손익 및 수익률(%)만 단독 표시
• 수수료 및 세금 시뮬레이션: 위탁수수료(0.015%) 및 증권거래세(0.18%) 자동 차감 반영
• 계좌 초기화 기능: '🔄 계좌 리셋' 버튼 클릭 시 언제든 1억 원 및 기본 시장 종목 목록으로 복원 가능

나. 주문 및 체결 엔진
• 지원 시장: 국내 주식(KOSPI, KOSDAQ), 미국 주식(NYSE, NASDAQ)
• 호가 및 주문 유형: 시장가, 지정가, 스탑로스 주문
• 시세 데이터 연동:
  - ✏️ 실시간 현재가 직접 수정/동기화(updateStockPrice)
  - 🔄 원클릭 외부 실시간 시세 동기화 (네이버/야후/키움)

다. 📊 트레이딩룸 인터랙티브 차트 매니저 [실제 증시 API & 줌 엔진 완비]
• 🌐 실제 공인 금융 API (네이버 금융 fchart / 야후 파이낸스) 차트 데이터 100% 실시간 연동:
  - 허위 난수 차트를 배제하고 실제 거래소 과거 및 최신 시/고/저/종/거래량 캔들스틱 정밀 렌더링
  - 국내 종목: 네이버 금융 fchart 공식 API (일봉/주봉) 및 야후 파이낸스 실시간 시세 (60분봉) 연동
  - 해외 종목: 야후 파이낸스 실시간 차트 API (일봉/주봉/60분봉) 연동
  - 10대 대표 종목(삼성전자, SK하이닉스, 현대차, NAVER, LG에너지솔루션, 에코프로비엠, 에코프로, AAPL, NVDA, TSLA) 실제 거래소 캔들 아카이브 탑재
  - 엑셀 업로드 신규 종목 실시간 비동기 실제 차트 API 자동 호출 및 캐싱
• 🔍 차트 크게보기 (+) / 작게보기 (-) / 100% 줌 컨트롤 및 마우스 휠 줌(Wheel Zoom):
  - 🔍+ 크게보기: 표시 캔들 개수를 줄이고 봉을 시원하게 확대하여 세부 변동과 꼬리를 큼직하게 관찰
  - 🔍- 작게보기: 표시 캔들 개수를 늘려 과거 장기 추세를 촘촘하게 축소 조망
  - 🔄 100%: 기본 배율(40봉) 복원
  - 좌상단 줌 배율(%) 및 데이터 출처 뱃지 실시간 표시
• ⏱️ 차트 주기(Timeframe) 원클릭 전환:
  - 일봉 (1D): 최근 일별 시/고/저/종 캔들스틱 (YYYY-MM-DD)
  - 주봉 (1W): 최근 주별 중장기 추세 캔들스틱 (YYYY-MM-DD (주))
  - 60분봉 (60M): 최근 정규장 시간대별 세부 시간봉 캔들스틱 (MM/DD HH:00)
• 🛠️ 차트 보조선 작도 툴킷: 수평 지지/저항선, 자유 추세선, 피보나치 되돌림선, 볼린저 밴드(20, 2), 내 평단가선, 작도 지우기
• 🌓 다크 모드 / 화이트 모드 2가지 테마 지원
• 📐 전체 화면 테이블 항목별 표준 정렬 체계 완비:
  - 종목명 / 코드: 좌측 정렬 (text-left)
  - 기타 모든 항목 (수량, 단가, 현재가, 평가금액, 손익, 수익률, 비중 등): 우측 정렬 (text-right)
  - 전략 처방 / 권장 주문 / 상태: 중앙 정렬 (text-center)
  - 적용 대상: 홈 대시보드 실시간 현황, 포트폴리오 잔고 현황, 리밸런싱 실행 테이블, 엑셀 파싱 목록, 자동 매매 일지 등 전 화면 일괄 동기화

라. 📑 실제 주식 잔고 엑셀 업로드 [전 영역 완전 무결성 단독 동기화]
• 🔄 기존 주식 및 가상 예수금 100% 완전 삭제 후 엑셀 주식만 단독 교체 등록 (Replace All):
  - 엑셀 업로드 시 기존 잔고 및 가상 예수금 리셋 (cashKRW = 0, isCustomPortfolio = true)
  - getStockByCode 정밀 매핑으로 엑셀의 모든 종목이 누락 없이 100% 등록
  - localStorage(stockcraft_custom_stocks_v1) 영속화로 새로고침 후에도 유지
• 📊 5대 전 화면 실시간 일괄 동시 연동:
  1) 🏠 홈 / 대시보드: 총평가자산 및 누적평가손익 내가 등록한 종목 기준 단독 반영 / 내 보유 주식 현황 단독 표시
  2) 📊 종목 시세 & 매매: 좌측 리스트 엑셀 주식만 단독 표시 & 1번 주식 차트/호가창 자동 선택
  3) 💼 포트폴리오 분석: 보유주식 잔고현황 7개 열 테이블 및 도넛 차트 단독 반영
  4) ⚖️ 리밸런싱 전략실: 옵션 1(개별) & 옵션 2(포트폴리오) 내가 등록한 종목만 단독 표시
  5) ⚙️ 지표 & 전략 설정: 등록된 포트폴리오에 실시간 연동되어 맞춤형 전략 파라미터 적용
  6) 📑 엑셀 업로드 시뮬레이션: 파일 변경 시 이전 미리보기 즉시 초기화 후 신규 파싱 목록만 단독 표시
  7) 🔝 최상단 공통 헤더: 총자산=엑셀 평가금액, 예수금=0원, 총손익=엑셀 순수 손익/수익률

마. ⚖️ 리밸런싱 전략 엔진 및 ⚙️ 기술적 지표 & 전략 파라미터 대시보드
1) [옵션 1] 개별 단일 종목 리밸런싱 전략 (Single-Stock Strategy):
  - 사용자 설정 지표(RSI, 이동평균선, 목표익절률, 손절선, 최대편중도)를 실시간 반영하여 정밀 처방 제시
2) [옵션 2] 전체 보유 종목 포트폴리오 리밸런싱 전략 (Whole-Portfolio Strategy):
  - 내가 등록한 종목들만을 100% 대상으로 목표 배분 모델 적용
  - 중립 균형형 (현금 10% + 주식 균등분산), 공격 성장형 (현금 5%), 안정 방어형 (현금 20%)
  - ☑️ 보유 종목 선택 리밸런싱: 테이블 체크박스 및 하단 보유 종목 카드에서 원하는 종목만 선택하여 '선택된 종목만 일괄 리밸런싱 실행' 지원 (미선택 종목 100% 보존)
3) [옵션 3 & 전용 메인 탭] ⚙️ 기술적 지표 & 전략 파라미터 설정 대시보드 (tabPane-config):
  - 상단 메인 네비게이션 탭 바에서 '⚙️ 지표 & 전략 설정' 원클릭 즉시 열람
  - 리밸런싱 전략실 내부 옵션 3 카드 클릭 시에도 즉시 해당 대시보드로 자연스러운 모드 전환
  - 4대 설정 카드 완비:
    ① 📈 RSI 기술적 지표: 과매수 기준선(pt), 과매도 기준선(pt), 계산 주기(일)
    ② 📉 이동평균선(MA): 단기(5일), 중기(20일), 장기(60일) 주기 조절
    ③ 🎯 익절 & 손절 규칙: 목표 익절률(%), 분할 매도 비율(%), 손절 제한선(%), 손절 축소 비율(%)
    ④ ⚖️ 포트폴리오 편중도 & 현금 버퍼: 단일 종목 최대 허용 비중(%), 목표 현금 버퍼(%), 눌림목 추가매수 하락폭(%)
  - 💾 '설정 저장 & 즉시 적용' 클릭 시 실시간 리밸런싱 엔진 및 처방 분석 자동 갱신
  - 🔄 '기본값 복원' 클릭 시 표준 권장 파라미터로 즉시 롤백
  - ⚖️ '리밸런싱 전략실로 이동' 바로가기 버튼 제공

## 4. 개편된 5대 정보 구조도 (IA: Information Architecture)
StockCraft (상단 5대 메인 네비게이션 체계)
├── 1. 📊 종목 시세 & 매매 (tabPane-trading)
│   ├── 엑셀 등록 주식 단독 리스트 (기존 종목 삭제 후 교체)
│   ├── ⏱️ 시세 차트 주기 선택 (일봉 1D / 주봉 1W / 60분봉 60M)
│   ├── 🔍 차트 크게보기(+) / 작게보기(-) / 100% 줌 컨트롤
│   ├── 🛠️ 차트 보조선 작도 툴킷 (수평선, 추세선, 피보나치, 볼린저밴드, 평단가선)
│   ├── 실시간 현재가 직접 수정 모달
│   ├── 10단계 호가창 및 실시간 체결 내역
│   └── 주문 패널 (매수/매도/정정/취소)
├── 2. 💼 보유 주식 포트폴리오 (tabPane-portfolio)
│   ├── 보유 잔고 테이블 (내가 등록한 주식 단독 반영, 항목별 표준 정렬)
│   ├── 자산 배분 비중 분석 (도넛 차트)
│   └── 상세 트레이딩 통계 (MDD, 승률, 샤프지수 등)
├── 3. ⚖️ 리밸런싱 전략실 (tabPane-rebalance)
│   ├── [옵션 1] 개별 종목 전망 및 리밸런싱 진단 (선택 종목 진단)
│   ├── [옵션 2] 전체 보유 종목 일괄 리밸런싱 시뮬레이터 (선택 종목만 일괄 체결)
│   └── [옵션 3 카드] 클릭 시 ⚙️ 지표 & 전략 설정 대시보드로 즉시 전환
├── 4. ⚙️ 지표 & 전략 설정 (tabPane-config)
│   ├── RSI 과매수/과매도선 및 계산 주기 조정
│   ├── 이동평균선(MA 단기/중기/장기) 주기 조정
│   ├── 익절 목표 수익률 및 손절 제한선 조정
│   ├── 포트폴리오 편중도 경고선 및 현금 비중 조정
│   └── 설정 저장/복원 및 리밸런싱 전략실 바로가기
└── 5. 📑 엑셀 업로드 시뮬 (tabPane-excel)
    ├── 증권사 엑셀/CSV 드래그 앤 드롭 업로드 존
    ├── 샘플 엑셀 양식 다운로드
    ├── 업로드 데이터 실시간 미리보기 테이블
    └── 내 포트폴리오 일괄 적용 & 리밸런싱 시작
