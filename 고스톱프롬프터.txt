[맞고(GOSTOP) 프로젝트 작업 요구사항]
등록일시: 2026-10-21

1. 프로젝트 개요 & 타겟 정의
- 플랫폼: 모바일 웹 (반응형 모바일 전용 뷰포트, PWA 지원 고려)
- 게임 룰: 기본값 1:1 맞고 (점당 100원, 7점 이상 스톱/고)
- 화면 모드:
  * 가로 모드 (권장): 전통적인 맞고 판 구조 (바닥패 중앙, 좌우 또는 상하 획득패 배치에 최적)
  * 세로 모드: 한손 조작 가능하도록 상하 배치 및 가로 자동 회전 대응
- 주요 타겟: 별도 앱 설치 없이 가볍게 즐기려는 캐주얼 유저

2. 모바일 웹 핵심 화면(UI) 레이아웃 구조
- 가로 모드 (약 16:9 ~ 20:9 비율 기준) 레이아웃 구조:
+--------------------------------------------------------------+
| [상대 프로필/점수]             [상대 획득패: 광/열/띠/피]      |
+--------------------------------------------------------------+
|                                                              |
|        [중앙 덱]       [바닥패 영역 (짝수개 8~12장)]          |
|                                                              |
+--------------------------------------------------------------+
| [내 획득패: 광/열/띠/피]       [내 프로필/실시간 점수/흔들기]  |
+--------------------------------------------------------------+
|                  [내 손패 영역 (10장)]                       |
|         *터치 시 튀어오름 / 바닥 패 매칭 하이라이트          |
+--------------------------------------------------------------+
- 모바일 전용 UX 필수 요소:
  * 전체화면(Fullscreen API): 게임 시작 시 전체화면 진입 버튼 제공
  * 패 터치 및 매칭 판정:
    - 바닥에 먹을 수 있는 패를 빛나는 테두리(Highlight)로 직관적 표시
    - 바닥에 같은 월이 1장일 때 원탭 시원한 매칭 지원
    - 바닥에 같은 월의 패가 2장 깔려 있을 경우 팝업/확대 선택 인터랙션
  * 오작동 방지: 터치 스크롤이나 당겨서 새로고침 방지 처리

3. 핵심 게임 시스템 및 룰 명세
- 기본 규칙:
  * 패 분배: 나/상대 각 10장, 바닥 8장 (짝수), 중앙 덱 20장 + 보너스 2장
  * 승리 조건: 7점 이상 달성 시 '고(Go)' 또는 '스톱(Stop)' 선택
- 특수 룰 지원:
  * 바닥패 짝수 유지: 바닥패는 기본적으로 짝수개로 관리되어 싹쓸이(판쓸이) 시 정상 피 강탈 연동
  * 보너스패/조커:
    - 시작 전 바닥에 깔리면 선공자가 즉시 피로 가져가고 바닥은 8장(짝수)으로 보충
    - 덱에서 뒤집으면 뒤집은 사람이 가져가고 상대 피 1장 강탈 + 덱에서 1장 추가 뒤집기
    - 손패에서 내면 즉시 피로 가져가고 상대 피 1장 강탈 + 덱에서 손패 1장 보충 후 정상 손패 출도
  * 뻑(설사) 및 싼 패 먹기:
    - 뻑: 첫 뻑, 3연속 뻑 승리 룰
    - 타뻑 먹기: 상대가 싼 패를 내가 먹으면 상대 피 1장 강탈
    - 자뻑 먹기: 내가 싼 패를 내가 직접 먹으면 상대 피 2장 강탈
  * 쪽 / 따닥 / 쓸:
    - 쪽, 따닥, 쓸(판쓸이) 발생 시 상대 피 1장 강탈
  * 박(배수) 시스템: 광박, 피박, 고도리박, 멍텅구리(열끗 7장 이상), 흔들기(2배), 폭탄(2배)

4. 백엔드 및 통신 아키텍처 (단계별)
- 1차 배포: GitHub Pages 호스팅 기반 싱글/스마트 AI 대전 및 PWA 모드 지원
- 2차 확장: WebSocket 기반 실시간 1:1 대전 지원

5. 모바일 웹 맞고 게임 기획 명세서 (GDD)
- 프로젝트명: 천하제일 맞고전 (가칭)
- 핵심 루프: 1:1 맞고 대국 -> 승리/패배 머니 정산 -> 점수 및 승률 갱신
- AI 난이도 시스템: 스마트 AI (패 계산, 피 모으기, 견제, 고/스톱 판단)

6. 사운드(SFX & BGM) 기획 명세서
- Web Audio API 기반 무지연 타격 사운드:
  * 카드 낼 때: 딱! 화투패 착 달라붙는 묵직한 타격음
  * 바닥 매칭: 찰싹! 패가 부딪치는 찰진 마찰음
  * 쪽 (Kiss): 뽀뽀 쪽! 소리와 함께 상대 피 1장 강탈
  * 따닥 / 쓸: 통쾌한 타격음 + 상대 피 1장 강탈
  * 뻑 (설사): 뿡/뿌직 익살스러운 사운드
  * 자뻑 먹기: 쾅! 강력한 타격음과 함께 상대 피 2장 강탈
  * 고/스톱 음성 및 BGM 지원

7. 4차 추가 개선 요청사항 (2026-10-21)
- 화투판 배경 색상을 실제 전통 고스톱 느낌의 "국방색 모요"(국방색 카키 톤 펠트 매트) 질감 및 색상으로 변경 적용.
- 화투 카드의 뒷배경이 투명하지 않고 깔끔한 백색(불투명 미색) 바탕이 되도록 SVG 및 카드 슬롯 배경 전면 처리.

8. 5차 추가 개선 요청사항 (2026-10-21)
- 화투 카드 빨간색 테두리 바깥의 미색 여백(마진) 완전 제거 (실제 화투 테두리 크기 90.6x153.8에 맞춘 정밀 슬라이스 및 배경 처리).
- 핸드폰 접속 시 회전 가이드 오버레이를 띄우지 않고, 세로 상태에서도 CSS 90도 자동 회전 및 전체화면 처리를 통해 무조건 가로 맞고판 화면으로 즉시 시작하도록 개선.

9. 6차 추가 개선 요청사항 (2026-10-21)

11. 8차 추가 개선 요청사항 (2026-10-21)
- 화투패 그래픽과 게임 엔진 데이터 불일치 전수 교정:
  1) Marcus Richert 화투 마스터 벡터 스프라이트(12열 x 4행) 실제 도판 배치와 cards.js의 48장 패 1:1 매핑 완전 일치화 (광이 엉뚱한 광을 먹거나 다른 월 패가 매칭되는 현상 근본 차단).
  2) 실제 도판 구조: 1행(1~3월), 2행(4~6월), 3행(7~9월), 4행(10월, 12월 비, 11월 오동)에 맞춘 정밀 좌표 전수 교정.
- 정통 한국 고스톱 패 따오기(매칭) 조작감 및 인터랙션 고도화:
  1) 손패를 탭했을 때 바닥에 1장만 매칭될 경우, 바닥에 하이라이트된 해당 패를 탭하거나 손패를 탭하여 시원하게 '착!' 소리와 함께 즉시 따오기 가능하도록 개선.
  2) 바닥에 같은 월이 2장 깔려 있을 때, 사용자가 가져올 패를 바닥에서 직접 선택하여 획득하는 정통 고스톱 규칙 완벽 연동.
--------------------------------------------------
12. 9차 추가 개선 요청사항 (2026-10-21)
- 보너스 쌍피(복돼지 2피 / 황금 3피) 한국 정통 맞고 게임룰 완벽 적용:
  1) 시작 전 바닥 보너스 패 룰: 게임 시작 시 바닥에 보너스 패가 깔리면, 선(선공자)이 해당 보너스 패를 즉시 피로 가져가고, 덱에서 1장을 추가로 뽑아 바닥패 8장을 정상 보충 (화면에 "바닥 보너스 쌍피 획득!" 연출).
  2) 게임 중 덱 뒤집기 보너스 패 룰: 대국 진행 중 덱에서 보너스 패를 뒤집은 플레이어가 해당 보너스 패를 즉시 피로 획득하고 상대방 피 1장을 강탈하며, 덱에서 1장을 추가로 뒤집어 정상 턴 진행 (화면에 "보너스 쌍피 뒤집기 성공! 상대 피 1장 강탈" 연출).
  3) 손패에서 보너스 패를 낼 때도 상대 피 1장 강탈 및 덱 추가 1장 보충 룰 보장.

13. 10차 추가 개선 요청사항 (2026-10-21)
- 바닥패 짝수개 유지 및 싹쓸이(판쓸이) 피 강탈 룰 강화:
  * 바닥패는 기본 8장(짝수)으로 시작하며, 손패에서 보너스 패를 낼 때 덱에서 손패 1장을 즉시 보충받고 정상 손패를 냄으로써 바닥패의 짝수 패리티와 판쓸이 기회를 보장.
- 뻑(싼 패) 먹기 피 강탈 규칙 적용:
  1) 타뻑 먹기: 상대방이 싼 패(바닥 3장 묶음)를 내가 먹었을 때 상대 피 1장 강탈 ("싼 패 먹기! 상대 피 1장 강탈" 연출).
  2) 자뻑 먹기: 내가 싼 패(바닥 3장 묶음)를 내가 직접 먹었을 때 상대 피 2장 강탈 ("💥 자뻑 먹기 대성공! 상대 피 2장 강탈!" 연출).
- 덱에서 뒤집은 패가 보너스 패일 때: 즉시 피로 가져오고 상대 피 1장 강탈 후 추가로 1장 더 뒤집는 연출 및 시퀀스 강화.
