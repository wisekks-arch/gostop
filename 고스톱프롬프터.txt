[맞고(GOSTOP) 프로젝트 작업 요구사항]
등록일시: 2026-10-21

1. 프로젝트 개요 & 타겟 정의
- 플랫폼: 모바일 웹 (반응형/모바일 전용 뷰포트, PWA 지원 고려)
- 게임 룰 기본값: 1:1 맞고 (점당 판돈, 7점 이상 스톱/고)
- 화면 모드:
  * 가로 모드 (권장): 전통적인 맞고 판 구조(바닥패 중앙, 좌/우 또는 상/하 획득패) 배치에 최적.
  * 세로 모드: 한 손 조작 가능하나 패 배치 및 애니메이션 영역이 좁아 UI 압축 설계 필수.
- 주요 타겟: 별도 앱 설치 없이 가볍게 즐기려는 캐주얼 유저 또는 사내/커뮤니티 미니게임 이용자.

2. 모바일 웹 핵심 화면(UI) 레이아웃 설계
- 가로 모드(예: 16:9 ~ 20:9 비율 기준) 레이아웃 구조:

|        [중앙 덱]       [바닥패 영역 (최대 12~14장)]            |
|                                                              |

+--------------------------------------------------------------+
|                  [내 손패 영역 (10장)]                       |
|         *터치 시 튀어오름 / 바닥 패 매칭 시 하이라이트       |
+--------------------------------------------------------------+
- 모바일 웹 전용 UX 필수 요소:
  * 전체화면(Fullscreen API) 유도: 게임 시작 시 전체화면 진입 버튼 제공 (브라우저 주소창 숨김 처리).
  * 패 터치 및 선택 판정:
    - 스마트폰 화면 크기를 고려해 손패 터치 영역(Hitbox)을 카드 그래픽보다 10~20% 넓게 설정.
    - 손패 선택 시 바닥에 먹을 수 있는 패를 빛나는 테두리(Highlight)로 직관적 표시.
    - 바닥에 같은 월의 패가 2장 깔려 있을 경우 팝업/확대 선택 인터랙션 구현.
  * 오작동 방지: 모바일 웹 브라우저의 기본 제스처(스와이프로 뒤로가기, 핀치 투 줌, 당겨서 새로고침) 방지 처리.

3. 핵심 게임 시스템 및 룰 명세
- 기본 규칙:
  * 패 분배: 선/후공 각 10장, 바닥 8장, 중앙 덱 20장.
  * 승리 조건: 7점 이상 달성 시 '고(Go)' 또는 '스톱(Stop)' 선택.
- 특수 룰 지원:
  * 보너스패/조커: 2피, 3피 카드 등장 시 중앙 덱에서 자동 보충.
  * 폭탄/흔들기: 같은 월 3장 보유 시 흔들기(승리 시 2배) 또는 바닥패와 연계한 폭탄(상대 피 1장 빼앗기).
  * 뻑/쪽/따닥/쓸:
    - 뻑(첫 턴 뻑, 3연속 뻑 승리 룰 등 옵션화).
    - 쪽/따닥/쓸 발생 시 상대 피 1장 강탈.
  * 박(배수) 시스템: 광박(광 점수 획득 시 상대 광 0개), 피박(피 점수 획득 시 상대 피 5~7장 이하), 고도리박, 멍텅구리(열끗 7장 이상).

- 2차 확장: WebSocket / Socket.io 기반 실시간 1:1 대전 지원

7. 4차 추가 개선 요청사항 (2026-10-21)
- 화투판 배경 색상을 실제 전통 고스톱 느낌의 "국방부 담요"(국방색/카키 울 펠트 매트) 질감 및 색상으로 변경 적용.
- 화투 카드의 뒷배경이 투명하지 않고 깔끔한 순백색(불투명 흰색) 바탕이 되도록 SVG 및 카드 슬롯 배경 전면 처리.

8. 5차 추가 개선 요청사항 (2026-10-21)
- 화투 카드 빨간색 테두리 바깥의 흰색 여백(마진) 완전 제거 (실제 화투 테두리 크기 90.6x153.8에 맞춘 정밀 슬라이스 및 배경 처리).

9. 6차 추가 개선 요청사항 (2026-10-21)
- 화투 카드 외곽에 모든 48장 패에 균일하고 적당한 약 1.5px 정통 레드 테두리(#d62828 / #b91c1c) 적용.
